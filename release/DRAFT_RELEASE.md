# v0.1.0 — Quran Handheld prototype (DRAFT)

Offline Hafs/Madinah reader for Waveshare ESP32-S3-ePaper-3.97, with portrait full pages, landscape sections, saved position/orientation, page selection, short-power blank/restore and three-minute sleep.

Install both folders from Quran_SD_Card.zip at the FAT32 card root. Build/upload the sketch following docs/INSTALLATION.md. No precompiled firmware is supplied without a verified build.

Assets: Quran_SD_Card.zip, Quran_Handheld_Source.zip and SHA256SUMS.txt. The source archive includes the owner-supplied four-part enclosure 3MF. Quran sources and terms are in ATTRIBUTION.md and LICENSES/.

Keep draft/private until CI, page review and enclosure provenance are resolved.
